# Video Toy keys

Generated by `./run.sh keycard` from `src/keys.gd`; do not edit by hand.
The printable version is [key-card.png](key-card.png).

## Basics

| Keys | What |
| --- | --- |
| `click` | spawn the selected icon at the mouse |
| `right-click` | remove the nearest icon |
| `Space` | spawn somewhere |
| `1-9` | select a toolbox slot · Del removes it |
| `X` | recolor the slot |
| `P` | next palette |
| `C` | clear the stage |
| `H` | hide the HUD (clean capture) |
| `Esc / ☰` | menu: panic, blackout, attribution, rigs, clip |
| `drop image / .svg / .ttf .otf / .txt / .ogv / rig .zip` | raster slot (Shift: chroma backdrop) / icon / font for words / word list / video slot / import rig |
